# Digital & Smart Construction Laboratory Website

This folder contains a GitHub Pages-ready redesign of the Digital & Smart Construction Laboratory website.

The current version is a concise multi-page research site. It foregrounds the DiSC Lab identity, research program, active sponsored work, software platforms, publications, team outcomes, teaching, news, and graduate opportunities. Dr. Hexu Liu is presented clearly as the lab director without turning the home page into a personal profile.

## Files

- `index.html` - concise research-led home page.
- `research.html` - research agenda, active projects, and selected completed projects.
- `platforms.html` - software systems and research prototypes with demonstrations.
- `publications.html` - recent advances and foundational contributions.
- `people.html` - director, current researchers, and alumni outcomes.
- `teaching.html` - teaching innovation, courses, and mentorship.
- `news.html` - curated recent updates with a link to the live X feed.
- `join.html` - graduate research areas, background, materials, and deadlines.
- `styles.css` - responsive visual design and layout.
- `script.js` - small navigation and header behavior.
- `assets/hexu-liu-portrait.jpg` - local copy of the official WMU portrait used in the director summary.
- `assets/disc-lab-hero.png` - generated visual asset used as a background accent.

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `disc-lab`.
2. Upload these files to the repository root.
3. In GitHub, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/root` folder.
6. Save. GitHub will publish the site after the first Pages build finishes.
